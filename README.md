# The Digital Detective

This repository is my Diwali independent learning assignment, "The Digital Detective". In it I explore how my computer works, practise Terminal commands, learn how the operating system manages files and programs, work with binary and hexadecimal numbers, and use Git and GitHub to publish my work. Each mission has its own folder with a README that explains what I did and what I learned.

## My Learning
- I learned how a computer takes input, processes it, produces output and stores data.
- I learned to use Terminal commands to create, copy and move files safely.
- I learned how Git branches and commits help me track and publish my work.
