# The Digital Detective

This repository is my Diwali independent learning assignment, "The Digital Detective". In it I explore how my computer works, practise Terminal commands, learn how the operating system manages files and programs, work with binary and hexadecimal numbers, understand how computers communicate, and use Git and GitHub to publish my work. Each mission has its own folder with a README that explains what I did and what I learned.

## Topics explored
- Input, processing, output and storage (IPOS), hardware and software
- Terminal commands, file management, flags and pipes, package managers
- Operating system, processes, paths, storage and permissions
- Compilers and interpreters
- Decimal, binary and hexadecimal numbers, and text encoding
- Git, branches and Pull Requests
- Networks, DNS and how a website opens

## How to run the number converter
From the project folder, run:

```bash
python3 mission-05-numbers-data/number_converter.py
```

Enter a decimal number when asked, and the program prints its binary and hexadecimal forms.
