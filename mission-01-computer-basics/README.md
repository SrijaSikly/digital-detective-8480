# Mission 1 — Know your computer

## 1. Task / objective
In this task i have to explain how a computer takes input, processes it, produces output and stores results (IPOS). I also had to identify hardware and software that I use, and give examples of computer-based systems around me.

## 2. Work completed

### Task 1.1 — IPOS for one activity
Activity chosen: typing and saving a document in VS Code.

| Stage | What happens in my example? | Hardware / component |
|-------|-----------------------------|----------------------|
| Input | I press keys to type the text of my README file. | Keyboard |
| Processing | The CPU works out which key was pressed and adds that character to the document. The text I am typing is held temporarily in memory. | CPU and RAM |
| Output | The letters appear on the screen as I type. | Screen (display) |
| Storage | When I press Command + S, the file is written from memory to permanent storage. | SSD |

How the activity moves from input to output and storage:
When I press a key, the keyboard sends a signal to the computer. The CPU processes it using the editor software and keeps the text in RAM while I work, then sends the result to the screen so I can see it. RAM is temporary, so the text would be lost if the computer switched off. Saving the file copies it to the SSD, where it stays permanently.

## 4. My understanding
IPOS describes how a computer works. Input is the data I give it, processing is what the CPU does with that data, output is the result I see or hear, and storage is where the result is kept for later. RAM is temporary memory, it holds data only while the computer is on and in use, while an SSD keeps it permanently.
Hardware is the physical parts of a computer that I can touch, such as the keyboard and screen. Software is the programs that run on the hardware. Operating system software (macOS) manages the computer and its resources. Application software (Chrome, VS Code) helps me to do a task. Utility software (Activity Monitor) helps me check, maintain or protect the computer.
I also noticed that many everyday machines, like an ATM or a traffic signal, follow the same input, processing and output pattern as a laptop.
